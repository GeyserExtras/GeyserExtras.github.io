:::warning 
    All options below can be edited by the player, these set the defaults.

    If you dont want the player to be able to edit these options, set `enable-geyser-extras-menu: false` in config.yml.
:::

## `cooldownType`
#### Default: `"TITLE"`
#### Values: `"TITLE"`
Set the default combat cooldown indicator location for Bedrock Edition players.

## `showCoordinates`
#### Default: `true`
#### Values: `true` | `false`
Set the default visibility of the coordinate display for Bedrock Edition players.

## `advancedTooltips`
#### Default: `false`
#### Values: `true` | `false`
Set the default visibility of Geyser's Java Advanced Tooltips display for Bedrock Edition players. (F3+H on Java Edition)

## `customSkullSkins`
#### Default: `true`
#### Values: `true` | `false`
Set the default visibility of Geyser's Player Skull skin workaround for Bedrock Edition players.

## `adjustCooldownWithPing`
#### Default: `true`
#### Values: `true` | `false`
Set the default option for adjusting cooldown meter progress based on connection to the server.

Recommended to stay enabled as this can help with combat timing.

## `indicatorUpdateRate`
#### Default: `60.0`
#### Values: `any number from 5-300`
Set the default option for the display update rate of the combat cooldown indicator.
This can solve problems with flickering on higher frame rate monitors.
